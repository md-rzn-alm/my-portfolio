A responsive personal portfolio website for **Md Rizwan Alam | Data Analyst & AI/ML Enthusiast**.

## Files
- `index.html` — website content and sections
- `style.css` — responsive styling
- `script.js` — mobile navigation and active section behavior
- `assets/Md-Rizwan-Alam-Resume.pdf` — resume download

## Run locally
Open `index.html` in a browser.

## Deploy free with Vercel
1. Create a new GitHub repository (for example, `my-portfolio`).
2. Upload all files and folders from this project. Keep the `assets` folder.
3. Sign in at https://vercel.com/ using GitHub.
4. Select **Add New → Project**, import your portfolio repository.
5. For this static HTML website, leave Framework Preset as **Other**. Leave Build Command and Output Directory empty, then deploy.
6. Vercel will provide a public `.vercel.app` URL. Future GitHub pushes trigger new deployments.

## Update project links later
Open `index.html`, find the relevant project card, and replace the `link-pending` text with an `<a href="YOUR_URL">GitHub ↗</a>` link. Commit and push the change to GitHub; Vercel will redeploy.
